# Raycast Scripts

Scripts Raycast centralisés dans `nix-config`.

## Chemin géré par Home Manager

- Source repo: `modules/dotfiles/raycast/scripts`
- Cible locale: `~/.config/raycast/scripts`

## Setup Raycast

1. Ouvrir Raycast.
2. Aller dans `Settings` -> `Extensions` -> `Script Commands`.
3. Ajouter le dossier `~/.config/raycast/scripts`.
4. Reconfigurer les raccourcis clavier si besoin.
